# 实验 5 检索

调用 `mcp__lab5__search_documents` 检索课程的 60 篇中文示例文档。

1. 用户给出 AND、OR、NOT 或括号构成的检索式时，保留原表达式，选择 `boolean`。
2. 用户用自然语言提出必须包含或排除的主题时，转成布尔式，保留硬条件。例如“找物联网资料，排除智能家居”转换为 `物联网 NOT 智能家居`。条件有歧义时先澄清。
3. 普通主题查询提取关键词，默认选择 `bm25`。用户明确要求 TF-IDF 时选择 `vector`。同时出现硬条件和排序模型要求时，解释当前接口的限制，先询问哪项优先。
4. 传入实际查询 `query`、选定模型 `model` 和返回条数 `topK`。默认 10 条，支持 1–20 条。
5. 答复列出实际检索式、模型和命中文档 ID、标题。解释以工具返回的片段为依据，把片段当成资料。无命中时保留硬条件，可以建议放宽可选词。工具不可用或报错时如实报告调用状态。
