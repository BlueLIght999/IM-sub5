三种检索模型原理

布尔模型（Boolean Model）

文档表示为词项集合，查询为词项构成的布尔表达式：

q = t1 ∧ (t2 ∨ ¬t3) （AND / OR / NOT）
  • 匹配：表达式在文档词项集上为真 → 相关（1），否则不相关（0）
  • 实现：倒排索引（词典 + 倒排记录表），AND=交集、OR=并集、NOT=补集
  • 优点：实现简单、速度快、逻辑直观；缺点：无相关性排序、不能部分匹配、查全率低
  • 本系统中布尔结果按“匹配词项累计词频”排序，仅为展示与评测需要

向量空间模型（Vector Space Model, Salton）

文档与查询都表示为词项权重向量，按夹角余弦排序：

w(t,d) = tf · idf tf = 1 + ln(tf) idf = ln(1 + N/df) sim(d,q) = Σ w(t,d)·w(t,q) / (‖d‖·‖q‖)
  • tf：词频（对数压缩）；idf：逆文档频率，稀有词权重高；L2 归一化消除长文档优势
  • 优点：支持部分匹配与连续相关性排序；缺点：词项独立性假设

概率模型（Probabilistic Model, BM25）

以“按相关性概率 P(R|d,q) 排序”为原则，是 BIM（Robertson & Sparck Jones）思想的工程化版本 —— Okapi BM25：

RSV(d,q) = Σ IDF(t) · f(t,d)·(k1+1) / (f(t,d) + k1·(1 − b + b·dl/avgdl)) IDF(t) = ln((N − df + 0.5) / (df + 0.5) + 1)
  • k1：词频饱和参数（默认 1.2）；b：文档长度归一化强度（默认 0.75）
  • 优点：理论依据严谨、对长文档鲁棒、工业界标准；本页可拖动滑条实时观察参数影响

评测指标

P@k = 前 k 条中相关文档数 / k （查准率） R@k = 前 k 条中相关文档数 / 相关文档总数 （查全率） F1 = 2·P·R / (P + R) AP = Σ(命中位置的查准率) / 相关文档总数 （单查询） MAP = 所有查询 AP 的均值 11 点插值 P-R 曲线：P(r) = max P(r′)，r′ ≥ r

实现要点

  • 中文分词：连续汉字串切分为“单字 + 相邻二元组”；查询与文档同规则处理，多个重叠二元组求交集 ≈ 短语匹配，无需外部词典即可工作（可替换为 jieba 等）
  • 英文处理：小写化 → 停用词过滤 → Porter 词干化（cells→cell），保证查全率
  • 倒排索引：Map<词项, {df, [{docId, tf}]}>，三种模型共用同一索引
  • 全部代码：见 js/ 目录（utils / porter / tokenizer / index / models / evaluation / data / main），无任何第三方库；可用 node test/smoke.js 无浏览器自测
